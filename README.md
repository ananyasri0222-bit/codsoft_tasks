CodSoft Python Programming Internship:
This repository contains three Python projects developed as part of my CodSoft Python Programming Internship.

Projects:
1. To-Do List
   -A task management application that allows users to add, view, edit, mark as completed, and delete tasks. Task information is saved in a JSON file.
2. Calculator
   -A simple calculator that performs addition, subtraction, multiplication, and division.
3. Password Generator
   -A Python program that generates random passwords based on the length entered by the user.

Technologies Used:
- Python
- Visual Studio Code
- Git and GitHub

How to Run:
Make sure Python is installed, then run each program from the terminal:
python to_do_list.py
python calculator.py
python password_generator.py
